# Synthesize findings

Produce evidence-bound findings and natural next-step recommendations from a reviewed analysis artifact.

**Lessons.** When `kater ai-tools list` names `lessons` for this skill, read that file before you start and follow it: it is what this organisation learned using this skill. Record a new lesson about using it there, as vfs://guides/lessons.md says.

## Procedure

1. Read `## Execution evidence` and `## Review`; do not calculate or infer evidence that does not appear there.
2. Write each finding with its governing run identifier and returned field. State the selected parameter and its provisional status when it affects interpretation.
3. State caveats for truncation, incomplete coverage, blocked nodes, correlation, and limitations. Label a causal statement as a hypothesis unless the evidence supports causal inference.
4. Recommend the most useful next capability in context: a drill-down, dashboard, app, report, or scheduled workflow. A recommendation is never authorization to create, arm, or schedule it.
